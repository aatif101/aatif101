### Selected work

**[Easy A](https://easya.fyi)** · [Code](https://github.com/aatif101/easy-A)  
Course search for USF Tampa students. Compare instructors using historical grades, check the latest observed seats, and find classes that meet GenEd requirements. Launched for spring registration: 2,400+ page views in the first month, peaking at 500+ in a single day.

**[Microsoft PyRIT](https://github.com/microsoft/PyRIT/pull/3471)** · open-source fix  
Found that PyRIT's `MarkdownInjectionScorer` missed two zero-click exfiltration paths (shortcut-reference images and raw HTML `<img>`). Filed the [issue](https://github.com/microsoft/PyRIT/issues/3343) with a repro, wrote the fix and tests, got it merged.

**[Pfizer externship](https://github.com/aatif101/pfizer-externship)**  
Extract structured fields from supplier PDFs and answer questions with source-page citations. 97.9% table-extraction accuracy, with an eval harness tracking F1, latency, and cost. Built during my externship through Extern.

**[Car-sales agent](https://github.com/aatif101/dubizzle-car-agent)**  
Conversational agent over ~100 real used-car listings. The model only turns messages into tool calls; a deterministic check re-verifies every price it quotes, and guardrails live in code, not the prompt.

**[SPOTlight](https://github.com/JylerTackson/SPOTLight)** · Knight Hacks, team of 4  
Dashboard for Boston Dynamics Spot inspection data. Fine-tuned a 421M ModernBERT on AMD ROCm for inspection-event triage (0.805 macro-F1 on held-out missions).
